# WC3 Build Order Tracker

Static web app (no build step): open `index.html` in a browser.

- Pick a race, then click buildings / units / heroes / research to chain a build order.
- Timer with hotkeys (rebindable in Settings): **F8** start/pause, **F9** step done (stamps the time), **Shift+F8** reset.
  Hotkeys only fire while the page has focus (browser limitation).
- Running gold / lumber / supply totals per step; supply turns red when over the cap.
- Save/load builds (localStorage) and copy/paste them as JSON.

## Data and icons
- `data.js` is generated by `tools/build_data.py` from the `wc3data` npm package (costs, build times, food)
  plus a hand-written research table (approximate values - edit it to match your patch).
  `tools/extract_units.py` reads `wc3data`'s `units.js` as text.
- Only the Orc/neutral icons from the `w3-icons` npm package are bundled in `icons/`. Everything else shows a
  text tile. To add more, drop `icons/<BTNName>.png` (e.g. `icons/BTNFootman.png`, the in-game file name, shown as
  `icon` in `data.js`) next to the app and it is picked up automatically.
