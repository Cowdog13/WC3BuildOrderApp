# WC3 Build Order Tracker

Static web app (no build step): open `index.html` in a browser.

- Pick a race, then click buildings / units / heroes / research to chain a build order.
- Timer with hotkeys (rebindable in Settings): **F8** start/pause, **`** (backtick) step done (stamps the time), **Shift+F8** reset.
  Hotkeys only fire while the page has focus (browser limitation).
- Running gold / lumber / supply totals per step; supply turns red when over the cap.
- Save/load builds (localStorage) and copy/paste them as JSON.

## Replay import
**Import replay** reads a `.w3g` file in the browser (no upload), picks a player, and turns their train / build /
research commands into steps with the replay time shown as `replay @m:ss`. Identical units queued within 4 s become `×N`.
Not imported: hero skills, mercenaries/items, cancelled orders, and research ids that have no entry in `data.js`
(they are listed after the import). `node tools/check_replay.js game.w3g` prints the same result in a terminal.

## Overlay (desktop)
`desktop/` is an Electron wrapper: frameless, always-on-top, with system-wide hotkeys.
```
cd desktop && npm install && npm start
```
Run Warcraft III in **Windowed / Borderless** mode (an overlay cannot draw over exclusive fullscreen).
Hotkeys (global, rebindable in Settings): F8 start/pause, ` (backtick) step done, Shift+F8 reset, F7 overlay/full view,
F10 click-through. The overlay starts small, see-through and docked on the right edge with click-through on, so your
clicks go to the game; press F10 to turn click-through off, drag it where you want it (the position is remembered),
and F10 again. The see-through level is a slider in Settings (full view). Note: a global ` hotkey takes that key away
from every other program while the overlay runs. Without Electron, the **Overlay** button just shows the compact view.

## Data and icons
- `data.js` is generated by `tools/build_data.py` from the `wc3data` npm package (costs, build times, food)
  plus a hand-written research table (approximate values - edit it to match your patch).
  `tools/extract_units.py` reads `wc3data`'s `units.js` as text.
- `python3 tools/fetch_icons.py` downloads the missing icons (run it on your own computer).
- Only the Orc/neutral icons from the `w3-icons` npm package are bundled in `icons/`. Everything else shows a
  text tile. To add more, drop `icons/<BTNName>.png` (e.g. `icons/BTNFootman.png`, the in-game file name, shown as
  `icon` in `data.js`) next to the app and it is picked up automatically.
